 # Biblioteca JavaScript

Projeto desenvolvido em JavaScript para gerenciamento de livros.

Sistema de gerenciamento de uma biblioteca desenvolvido em JavaScript.

 ## ---Sobre o projeto---

O projeto simula um sistema de biblioteca, permitindo cadastrar, buscar, listar, emprestar e devolver livros, além de apresentar estatísticas sobre os livros cadastrados.

 ## ---Funcionalidade---

Listar todos os livros
Buscar um livro pelo título
Listar livros disponíveis
Cadastrar novos livros
Realizar empréstimos
Realizar devoluções
Exibir estatísticas da biblioteca

 ## ---Estrutura do projeto---

index.js — arquivo principal e menus do sistema
listarLivros.js — lista todos os livros
buscarLivro.js — busca um livro pelo título
listarDisponiveis.js — mostra os livros disponíveis
cadastrarLivro.js — cadastra novos livros
realizarEmprestimo.js — realiza empréstimos
realizarDevolucao.js — realiza devoluções
exibirEstatisticas.js — apresenta as estatísticas
dadosLivros.js — contém os livros cadastrados
Livro.js — classe utilizada para criar os livros
package.json — configuração do projeto
README.md — documentação do projeto


 ## ---Tecnologias utilizadas:---
JavaScript
Node.js
prompt-sync
Módulos JavaScript (import e export)


 ## ---Como executar:---

Primeiro, instale as dependências:

npm install

Depois, execute o programa:

node index.js
